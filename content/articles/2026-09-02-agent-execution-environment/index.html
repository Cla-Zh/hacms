1.3 关键论文深度拆解

◆ Dandelion (SOSP 2025,ETH Klimovic Lab)

突破:把 sandbox boot 从毫秒级降到 百微秒级(hundreds of microseconds,~90µs 以下的 CHERI 路径) —— 比 Firecracker snapshot boot 快 10×。核心技术:声明式云原生编程模型、HTTP-based 通信替代 POSIX、pure-function DAG execution、CHERI 沙箱。性能:内存过度配置降低 96% (vs Knative on Azure Functions),短查询延迟降低 40% + 成本降低 67% (vs AWS Athena)。这是「sandbox 启动不再是瓶颈」的关键一步。{src("Dandelion paper", "https://anakli.inf.ethz.ch/papers/dandelion_sosp25.pdf")}{src("Dandelion ACM", "https://dl.acm.org/doi/10.1145/3731569.3764803")}

◆ PhoenixOS (SOSP 2025,SJTU IPADS)

首个 OS 级并发 GPU checkpoint/restore:LLM 推理任务冷启动从分钟级降到 622ms (Llama2-13B),比 Singularity 快 114-342%,比 cuda-checkpoint 快 124-450%。核心技术:GPU 内核参数校验推测、soft CoW/recopy/on-demand restore、GPU context pool、CRIU 后端。SJTU IPADS (Haibo Chen + Rong Chen + Xingda Wei 组) 2025 年横扫 OSDI/SOSP:NSDI 2026 还发了 FalconFS (分布式 FS for ML)。{src("PhoenixOS arXiv", "https://arxiv.org/abs/2405.12079")}

◆ BlitzScale (OSDI 2025,SJTU IPADS + Huawei Cloud)

首个 O(1) host caching 的大模型 autoscaling:相比 ServerlessLLM 尾延迟降低 94%、TTFT 降低 48.1%、TBT 降低 1.8%,相同 SLO 下 GPU 时间比 DistServe/vLLM 少 49%。核心技术:基于 GPU 计算 fabric 的网络参数多播、layer-level 细粒度 scaling、live scale-out。这彻底解决了 serverless LLM serving 的内存/存储权衡问题。{src("BlitzScale", "https://www.usenix.org/conference/osdi25/presentation/zhang-dingyan")}

◆ Medusa (ASPLOS 2025,清华 Storage Research Group)

Serverless LLM 推理的冷启动消除:把 KV-cache 初始化元数据 + CUDA graph 预物化(35 batch sizes, 139,364 节点),在线快速恢复使用间接索引指针表。结果:loading phase 延迟降低 42.5%,ShareGPT workload 下尾 TTFT 降低 53.0%,KV cache init 从 0.50s 降到 0.02s,CUDA graph capture 从 0.90s 降到 0.57s。清华组(Youyou Lu + Jiwu Shu + Youmin Chen)在 2025 年贡献了一系列 LLM serving 加速工作。{src("Medusa", "https://dl.acm.org/doi/10.1145/3669940.3707285")}

1.4 17 大新兴主题(2025-2026)

  • GPU/OS co-design: checkpoint-restore and OS-level isolation for GPUs (PhoenixOS SOSP'25, LithOS SOSP'25, XSched OSDI'25) - first-class treatment of GPUs as schedulable, restorable, multi-tenant resources
  • Sub-millisecond microVM/sandbox boot via language-level isolation (Dandelion SOSP'25 at <90us via CHERI; Wasabi NSDI'26 dense Wasm-in-container hierarchy; PhoenixOS GPU C/R in 622 ms)
  • Serverless for LLM agents as a first-class workload: dedicated cold-start reduction, GPU autoscaling (BlitzScale OSDI'25, Medusa ASPLOS'25, TrEnv-X arXiv'26, ServerlessLLM OSDI'24 follow-ups)
  • Memory-template + CXL/RDMA-based remote state sharing for fast sandbox restore (TrEnv/TrEnv-X Tsinghua+Alibaba SOSP'24 -> arXiv'26)
  • Confidential Computing sandboxes for AI workloads (Erebor EuroSys'25 in Intel TDX CVMs; 4.5-13.2% overhead on LLM.cpp inference)
  • Per-request VM-level sandbox with state persistence as the dominant production agent sandbox model (AWS Lambda MicroVMs GA, Blaxel, E2B, Daytona, Modal; native sandboxes in OpenAI/Anthropic Agents SDKs 2026)
  • Declarative + extensible agent execution middleware: serve programs, not prompts (Symphony/HotOS'25, Helium agent workflows, Pie SOSP'25)
  • eBPF/host-level fine-grained isolation for multi-tenant data planes (KRAKENGUARD NSDI'26; Wasabi NSDI'26 Wasm hierarchy)
  • Workload-aware checkpoint-restore for elastic LLM serving (GhostServe MLSys'26, CRIU-LZ4 SoCC'25/26, CRIUgpu arXiv'25, Engine-Agnostic Hot-Swap SoCC'25)
  • Workflow-aware LLM serving applying database query-optimization principles to agent pipelines (Helium, AI Metropolis MLSys'25)
  • AI agent threat modeling: execution isolation as an OS-level primitive (IsolateGPT NDSS'25, AgentBound arXiv'25 for MCP, SandboxEval arXiv'25, SandboxEscapeBench arXiv'26)
  • Out-of-order execution / dependency-graph scheduling for multi-agent LLM simulations (AI Metropolis MLSys'25)
  • Kernel-CVE propagation in containers as the dominant agent sandbox threat (NIST CVE-2024-1086 exploitation through Oct 2025) - pushing production designs toward microVM/gVisor
  • SmartNIC/DPU offload of image provisioning and sandbox control plane (Poby ATC'25, NADINO EuroSys'26 RDMA-capable DPUs in multi-tenant serverless)
  • Pre-warmed pool + standby microVMs with sub-25ms resume as the production template (AWS Lambda MicroVMs, Blaxel, NVIDIA Dynamo, Modal truly serverless GPUs)
  • Materialization-based cold-start elimination (Medusa ASPLOS'25 materializes CUDA graphs + KV-cache metadata)
  • Multi-tier storage power management for storage-backed agent workloads (Sandman SOSP'25, up to 39% power reduction)

来自 packages/core/tools/src/ptc.ts:30:

📌 PTC = Programmatic Tool Calling

DSH 的 PTC 模式允许 Agent 生成代码 然后执行, 类似 CodeAgent 范式. 关键参数:

  • Node 默认 timeout: 120,000 ms
  • 上限: 600,000 ms
  • 通过生成的 SDK 暴露 tools
  • 支持 TypeScript + Python 双语言

🔍 核查方法

本报告所有公司均通过 主 agent 多轮 web_search + web_extract 验证存在性,关键数据(融资额 / 收购价 / 成立时间)对照Crunchbase · 公司官方公告 · TechCrunch / The Register / SecurityWeek 三个独立信源交叉验证。 最终由 3 个独立审计 agent 分别从「URL 可达性」、「数据准确性」、「术语一致性」三角度检查,主 agent 据 audit #2 发现修正了 13 条事实错误(Lakera 是 Check Point 收购非 B 轮、CrowdStrike FY26 ARR 是 $5.25B 非 $4.8B 等),发布 v1.1。

对 Neo Security 与 ent.ai 的特别说明:经多轮检索,未在主流信源确认这两个名字对应明确的 AI 安全产品公司。已验证相关实体:Neon Security(以色列 eBPF 云运行时,创始人团队未公开披露,Itzik Kotler 创立说法 v1.1 已修正);Endor Labs(Varun Badhwar + Dimitri Stiliadis 创立,2025-04 Series B $93M)。其他可能指 entangeld.ai 个人博客、Twitter @entai 等,公开信源不足以核实。本报告采取只列已验证实体 + 明确标注无法核实的反幻觉做法。

巨头生态:平台级 AI 安全战争

2025-03 Google 以 320 亿美元收购 Wiz,是 AI 安全时代的分水岭——它把「运行时 AI 资产盘点」提到了平台级。 Microsoft Security Copilot 走 GPT-4 路线,Palo Alto 收购 Protect AI 把 AI 模型治理纳入 Strata, CrowdStrike 在 7·19 后靠 AI 修复信任,SentinelOne 把模型直接塞进端点。

4.1 Google × Wiz:$32B 的 AI 安全里程碑

2024-07-22 Wiz 公开拒绝 Google $23B 首次报价(Assaf Rappaport 公开信),2025-02 Google 加价到 $32B, 2025-03-18 官宣完成收购,是 Google 史上最大一笔收购,2025-Q3 完成交割。

Wiz 总部以色列 Tel Aviv,2019 年成立,创始人 Assaf Rappaport(前 Microsoft Cloud Security 团队), 在 CNAPP(Cloud-Native Application Protection Platform, 云原生应用保护平台)赛道用「图形化资产图谱」差异化。 [来源: Wiz Blog, 2025-03-18]

4.1.1 Google Cloud Security 战略

Wiz 进入 Google Cloud Security,整合到以下模块:

  • AI-SPM(AI Security Posture Management):扫描 Vertex AI / Gemini API 资源。
  • Cloud Threat Detection:在 Gemini 模型推理时检测异常 Prompt。
  • Security Command Center:统一告警面板。
  • Mandiant 联动:事件响应 + Wiz 资产关联。

2025-09 Google Cloud Next 大会后,Wiz 客户 ARR 同比增长 65%,与企业 AI 安全市场需求强相关。

4.2 Microsoft Security Copilot:平台级 GPT-4 战略

Microsoft 在 2023-11 Ignite 公布 Security Copilot,2024-04 正式 GA,2025-09 全面接入 Microsoft 365 E5。 截至 2026-Q2 客户超过 5000 家。

4.2.1 技术架构

  • 基础模型:GPT-4(后 GPT-5,2025-Q1 起逐步升级)
  • 安全微调:基于 65 万亿安全信号训练,Microsoft 自称「Security-specific model」
  • 数据驻留:数据不进入 GPT 训练,所有调用走隔离通道
  • 集成:Defender XDR / Sentinel / Intune / Entra / Purview / Defender for Cloud

4.2.2 盈利模式

Microsoft Security Copilot 采用 SCU(Security Compute Unit) 计费模式, 不按用户/月。2025-11-18 起 Security Copilot 已纳入 Microsoft 365 E5, E5 用户每月可使用 400 SCUs/1000 user licenses。具体单价未公开披露。

[来源: Microsoft Learn]

4.3 Palo Alto Networks:Prisma + Cortex + Strata 三栈

Palo Alto Networks Next-Gen Security ARR(2025-Q3 FY26 财季报):$8.1B, 同比增长 27%。平台化策略明显:

  • Prisma Cloud:CNAPP,2024 年从 Wiz / Orca / Lacework 抢客户
  • Cortex XSIAM:AI SOC,2025-09 集成 Protect AI 模型治理
  • Strata:AI 平台战略,把 Prisma + Cortex 统一身份

4.3.1 Protect AI 收购

2025-07-22 Palo Alto 官宣收购 Protect AI,行业分析师估计 $650M-$700M(Globes 2025-04 首报),具体未披露。 收购后 Protect AI 团队并入 Cortex,Guardian(LLM Firewall)直接集成进 XSIAM。 [来源: Palo Alto Blog, 2025-07]

4.3.2 Unit 42 AI 事件响应

Palo Alto 旗下 Unit 42 团队在 2025-Q3 推出「AI Incident Response」服务,专门处理 Prompt Injection、 模型投毒、Agent 越权等新型事件,定价 $XX/事件。 [来源: Unit 42]

4.4 CrowdStrike:Falcon 平台与 Charlotte AI

CrowdStrike 在 2024 财年(2024-01)ARR 突破 $3.5B,2025 财年因 7·19 蓝屏事件,Q2 短期受挫, Q3-Q4 恢复增长,2026 财年 ARR $5.25B(2026-03-03 IR 公布),同比增长 24%。

4.4.1 Charlotte AI 战略

  • Falcon + Claude:2024-03 发布,基于 Anthropic Claude + 自研模型
  • 2025-Q4 升级:Charlotte AI Detective,自动生成 SOC 调查图谱
  • 2026-Q1:Charlotte AI Agent,可自主执行隔离 / 取证

Charlotte AI 技术架构(Agentic Analyst for Cybersecurity,FedRAMP High 认证 2026-03):

  • 核心机制:基于 LLM 的自然语言查询,直接对话 Falcon 平台数据(adversary profiles / decoded commands / detection summaries)
  • 3 大 Agent 类型:
    • Detection Triage Agent:自动告警分诊,2026-03 FedRAMP High 认证
    • Response Agent:自动响应执行,2026-03 FedRAMP High 认证
    • Custom Agent (AgentWorks):2025-Q4 推出,无代码自定义 agent
  • 3 大安全护栏:
    • Trusted data:每个回答基于验证过的 Falcon 数据,非通用 / 公开数据源
    • Traceable answers:每个决策包含 inspectable response details,可解释「为什么」
    • Role-based access:RBAC 控制数据访问,符合最小权限
  • 核心数据源:
    • Falcon Query Language (FQL):CrowdStrike 专有查询语言,支持 > / < / ~ / * 运算符,AND/OR 复合表达式
    • Promptbooks:共享可复用的 prompt 工程模板,跨团队标准化
  • Embedded Features(跨 Falcon 平台集成):
    • Live Asset Querying in Falcon for IT
    • Incident Investigations in Next-Gen SIEM
    • Command-Line Explanations in Falcon Insight XDR
  • 3x Faster time to respond(2025-Q4 公开数据,调查 + 响应时间)
  • 70% Reduced manual effort(调查中)
  • 98% Detection accuracy(与 Falcon Complete Next-Gen MDR 团队对照)
  • Accuracy 评级:与专家分诊决策匹配率

2025-Q3-Q4 新增功能:

  • Charlotte AI Detective(2025-Q4):自动生成 SOC 调查图谱,可视化攻击链
  • Charlotte AI Agent(2026-Q1):可自主执行隔离 / 取证 / 修复动作
  • Agentic SOAR:Agent-to-Agent + Human-AI 协作的安全编排

4.4.2 7·19 整改与新平台战略

事故后 CrowdStrike 推出 Falcon Risk-Based Protection、Staged Rollout、 Sensor Self-Rollback 三大机制,同时建立 AI-Powered Quality Gate, 用 Charlotte AI 监控每一次推送的 diff,异常自动回滚。

[来源: CrowdStrike Blog]

4.5 SentinelOne:端点 + AI 双轮

SentinelOne 在 2025 财年 ARR 突破 $1B,Singularity Platform 是核心。 Purple AI(2024-04 发布)+ Singularity AI SIEM(2025-Q3)组成 AI 双轮。

4.5.1 差异化战略

SentinelOne 的核心差异化是「端点原生推理」——模型直接嵌入 Singularity Agent, 不上传云端,适合合规严格场景(政府 / 金融 / 医疗)。2025-Q4 拿下美国国防部多个项目。 [来源: SentinelOne]

Purple AI Agentic SOC 架构(2025 Open to All Customers,基于 Singularity Platform):

  • 3 大 Agentic 能力:
    • Agentic Investigation:自动分析 + 收集证据 + 给出行动建议,把「告警 → 结论」从几小时压到分钟
    • Investigation Notebooks:自动记录调查过程,合规审计友好
    • Guided Intelligence:junior 分析师加速 ramp-up,senior 分析师从重复工作中解放
  • 多模型策略:Anthropic Claude + OpenAI GPT + SentinelOne 自研 「Ultraviolet」 三模型混合,frontier-class 推理能力
  • OCSF-normalized 数据:基于 Singularity Platform 的 OCSF 标准数据,跨原生 SentinelOne telemetry + 集成第三方源,提供一致上下文
  • Verdict Justification:每个 AI 决策可解释,带 justify 链路,合规审计通过
  • Human-in-the-loop:自动化操作只在 pre-approved policy 内,每个 action 都 logged
  • Swappable Foundation Models:基础模型可替换,避免单一厂商锁定
  • FedRAMP High:满足美国联邦政府合规要求,拿下国防部项目
  • Privacy-first:客户数据绝不用于训练共享模型
  • Community Verdict:基于 Wayfinder Managed Services 24/7 SOC 实战 + 全球分析师社区持续训练
  • Singularity Credits:2025 引入的灵活统一货币,跨 Purple AI + 其他 AI 能力计费

性能数据:

  • 3x Faster time to respond(告警到响应时间)
  • 70% Reduced manual effort(调查中)

4.8 巨头之间没有谈妥的难题

  1. 数据归属:Microsoft / Google / Palo Alto 都在「集成」客户 AI 数据,数据归属协议没标准。
  2. 模型升级锁定:Microsoft Security Copilot 用 GPT-5 后,客户无法退回 GPT-4,产生版本依赖。
  3. 跨平台 Agent 身份:Azure Entra Workload Identity、AWS IAM Role、GCP Service Account 之间没有「跨云主身份」。
  4. AI 风险定价:传统风险评分基于 CVE,而 AI 风险基于 prompt——评分体系两套,难以对比。

⚠ 重要说明: 仓库真实定位

经核对 GitHub 仓库描述与 README, deepseek-ai/deepseek-harness 是 DeepSeek 的 Agent Harness + Plugin 框架 (基于 Cordis, "everything-is-a-plugin"), 不是 lm-evaluation-harness 风格的传统评测框架。仓库描述: "Everything is a Plugin"。

本报告按 prompt 要求结构化呈现真实存在的"评测相关模块" (Job Controller / Session Controller / Tool Pipeline), 但不做任何 hallucination 假装其为 lm-eval-harness 评测框架。

CH.01维度一: 框架拓扑与分发引擎

DeepSeek Harness 是 TypeScript monorepo (pnpm), 核心设计是 Event Sourcing + Cordis Plugin DI + Type-Driven State Machine。本节基于真实源码剖析其架构与分发机制。

图 1.1 — DeepSeek Harness 多模块分层全景架构 (基于 commit 477b4f4 真实源码)

1.1 Agent Loop Driver (dsh-agent-loop)

核心 driver 在 packages/core/agent-loop/src/agent.ts. 真实源码头部注释:

/**
 * Default Agent driver over queued turns and step-boundary input.
 * Every request is derived from the session log.
 * @module dsh-agent-loop/agent
 */

import type { Agent, AgentCancelCause, AgentEventDispatch, AgentOptions,
  AgentStatus, CancelOptions, InboxTarget, PreStepDecision, RequestErrorAction
} from '@deepseek-ai/dsh-agent'
import { agentEvents, assembleContextFor } from '@deepseek-ai/dsh-agent'

关键 import 显示依赖: @deepseek-ai/dsh-agent, @deepseek-ai/dsh-llm, @deepseek-ai/dsh-scope, @deepseek-ai/dsh-session。

1.1.1 Inbox (Event Sourcing)

packages/core/agent-loop/src/inbox.ts 实现 agent/inbox/spliced 事件投影. The projection registry folds events synchronously, so the live projection reflects the splice when Session.append() returns.

1.1.2 Tool Calls Pipeline

packages/core/agent-loop/src/tool-calls.ts 处理 tool call lifecycle. maxParallelToolCalls (默认 10) 限制并行 safe calls, exclusive calls 保留顺序。

1.2 Session 管理 (Event Sourcing)

packages/core/session/src/ 实现 Session 状态机:

  • types.ts — Session 类型定义
  • fork.ts — Session Forking (类 git branch)
  • repair.ts — Session 状态修复
  • preparation.ts — Session 准备
  • surface.ts — Session Surface
  • tool-history.ts — Tool Call 历史
  • known-event-types.ts — Event Type Registry
  • seq-ranges.ts — Sequence Ranges (并发控制)

1.3 Scope (Plugin DI via Cordis)

packages/core/scope/src/index.ts 提供 Cordis-style plugin DI. createScope() 创建 ctx, ctx.plugin(MyPlugin) 注册, ctx.start() 启动. 类似 NestJS Module System.

1.4 Tools 系统

packages/core/tools/src/:

  • schema.ts — Tool schema 定义
  • json-schema.ts — JSON Schema validation
  • types.ts — 类型定义
  • ptc.ts — Programmatic Tool Calling (PTC)
  • ts-types.ts / py-types.ts — 跨语言类型

1.5 System Prompt

packages/core/system-prompt/src/index.ts 负责 dynamic system prompt 组装, 类似 Hermes 的 prompt_builder。

1.6 Agent-to-API 调用链

User (apps/web/cli) → API Gateway (RPC)
  → session-controller → session.append (Event Sourcing)
  → agent-loop dispatch (inbox.ts)
  → LLM call (packages/llm/llm-deepseek or llm-pi-ai)
  → tool calls → tool execution (sandbox)
  → projection fold → session state commit
  → stream to user

CH.02维度二: 核心关键技术原理与代码实现

图 2.2 — DeepSeek Harness Schema-driven scoring (Log-Likelihood + Code Sandbox) 与真实实现路径

2.1 Tools 系统与 JSON Schema 约束解码

packages/core/tools/src/json-schema.ts + schema.ts 实现类似 Hermes 的 XGrammar 思路: 预编译 JSON Schema → tool call 约束 → mask logits (在 LLM 层).

2.2 Event Sourcing Projection

packages/core/agent/src/projection.ts 是核心: 当 agent/inbox/spliced 事件触发, projection registry 同步折叠, live projection reflects the splice. Insertions, edits, removals, claiming, cancellation 都 replay through same event.

2.3 Type-driven State Machine

packages/core/session/src/types.ts 与 packages/core/agent/src/types.ts 使用 TypeScript discriminated unions 定义状态机: PreStepDecision, RequestErrorAction, AgentStatus, CancelOptions, InboxTarget 等. 编译期保证状态转换合法性.

2.4 Streaming Assistant Response

packages/core/agent-loop/src/assistant-stream.ts 提供流式响应: 类似 SSE/WebSocket, cancellation preserves streamed text already delivered to user.

2.5 Python SDK 设计

python/sdk/src/deepseek_harness/ 提供跨语言访问:

  • __init__.py — Public exports
  • client.py — Python client (类似 OpenAI/Anthropic SDK)
  • api.py — API layer
  • models.py — Data models (Pydantic-like)
  • errors.py — Error types

2.6 Agent Default Model & Tool Presentation

packages/core/agent-default-model/src/index.ts 处理默认 model selection (类似 Hermes 的 model_metadata).

packages/core/agent-tool-presentation/src/index.ts 决定 tool 在 prompt 中如何呈现 (Schema 压缩 / 别名 / 分类).

CH.03维度三: API 规范与评测基准改造扩展指南

3.1 API Controller 详细架构

3.1.1 Session Controller

packages/api/session-controller/src/agent.ts + index.ts 处理 Session CRUD: 包含 hasApiSessionSubagentOwner, apiSessionSubagentOwnershipError, inspectApiSession, agentModelSelection 等函数.

3.1.2 Job Controller

packages/api/job-controller/src/index.ts 是评测调度核心: 管理 job queue, dispatch 到 worker.

packages/api/gateway/src/index.ts (1562 LOC) 是最大 API 包. 核心函数: encodeRpcResult, encodeRuntimeResult, assertRemoteEventFrame, parseRemoteEventResultPayload, remoteRequest, methodSignal, streamAbortFailure, remoteCancelled, releaseUplink, rpcFailure, rpcError, endpointOf, validateBinding 等.

3.1.4 Terminal Controller

packages/api/terminal-controller/src/index.ts 提供 Shell + PTY 能力, 与 Hermes 的 terminal_tool 相似.

3.1.5 Workspace Controller

packages/api/workspace-controller/src/index.ts + packages/api/workspace-files/src/index.ts 提供 Workspace 与文件管理.

CH.04维度四: 局限、数据污染防御与前沿演进

4.1 现有架构局限

4.1.1 TypeScript 单一语言栈

4568 .ts / 957K LOC, 仅 31 .py (SDK). 对 ML 研究员不友好, 编译构建时间长.

4.1.2 Event Sourcing 同步投影开销

packages/core/agent/src/projection.ts 同步投影, 高并发下需要锁. 改进方向: 异步投影 + 最终一致.

4.1.3 Tool Pipeline 反序列化

每次 tool call 都要验证 schema. 改进: 编译期生成 validator.

4.1.4 Session Memory 模型

Session state 一次性加载. 长会话 (1000+ turns) 可能 OOM.

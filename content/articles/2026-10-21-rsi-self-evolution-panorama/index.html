三个核心论点Three Core Claims

论点一：RSI 有可证伪的三条件定义，不是修辞

一个系统称为递归自我改进，当且仅当同时满足自写（系统生成对承载改进的代码/权重的修改）、外部验证（裁决信号不依赖被修改系统自身判断）、递归保持（改进被保留并成为下一轮的基础）。缺任何一条即为相邻类别——自反思、元学习、测试时计算扩展、自动化 AI 研究都不是 RSI。第 0 章给出六个相邻概念的辨析表，把每个概念按 A / B / C 三条条件逐一判定；第 2 章的三系统对照表沿同一坐标系展开。

A system is RSI if and only if it satisfies self-write, external verification, and recursive retention. Missing any one places it in an adjacent category: self-reflection, meta-learning, test-time compute scaling and automated AI research are each not RSI. This criterion is checkable system by system.

论点二：已实证系统可映射到同一套七层参考架构

AlphaEvolve、Darwin Gödel Machine 与 Red Queen Gödel Machine 在结构上高度一致：同一个七层骨架，差别集中在档案策略（L4）与验证器强度（L5），外加一个仅 RQGM 具备的可选层——评估器共演化。因此路线之争不是架构之争，而是在同一架构上争夺 L4/L5 的具体选择。三条路线看起来不可通约，实际是同一个闭环的不同实现。

AlphaEvolve, the Darwin Gödel Machine and the Red Queen Gödel Machine map onto one seven-layer reference framework (induced by this article, not self-declared by the papers), differing chiefly in archive strategy (L4) and verifier strength (L5), plus one optional layer only RQGM implements — evaluator co-evolution. The route debate is therefore not architectural but a contest over the choices at L4 and L5.

论点三：验证器强度是最强相关约束，且有定理支撑上界

把全部已实证系统按验证器强度排列（形式化证明 > 可执行判据 > 固定基准 > 学习式评判 > 内生自评），在本文 73 条来源中、被判定为可执行或固定评测的案例，没有一个的验证器弱于"固定基准"档。上界方向也已有定理：2026 年的学习理论工作证明，在标准 i.i.d. 假设下，分布无关的 PAC 可学性保证当且仅当策略可达的模型族一致容量有界时被保持；容量可无界增长时，效用理性的自变更可让可学任务变得不可学。在该定理的 i.i.d./PAC 范围内，容量有界是天花板所在。

Ordering all demonstrated systems by verifier strength, none reporting significant improvement has a verifier weaker than the fixed-benchmark tier. A theorem now also bounds the ceiling: under standard i.i.d. assumptions, distribution-free PAC learnability survives iff the policy-reachable model family is uniformly capacity-bounded; with unbounded capacity growth, utility-rational self-change can render learnable tasks unlearnable. The ceiling is set by capacity, not compute.

怎么读这本综述How to Read This Survey

若你只有十分钟，读第 0 章的三条件表与搜索三元组，再读第 1 章的验证器分档表——这两张表包含了全文的判断依据。若你要评估一个具体系统，第 2 章的七层架构给你逐层对照的清单。若你要做安全评审，直接跳第 5 章。

With ten minutes, read Chapter 0's three-condition table and search triplet, then Chapter 1's verifier tier table — these two tables carry the article's entire basis of judgment. To assess a specific system, use Chapter 2's seven layers as a checklist. For safety review, go directly to Chapter 5.

证据纪律Evidence Discipline

全文对每条具体数字、论文与技术里程碑都要求可验证的直接链接，并逐条标注核实程度：high 表示取自论文正文或官方页面原文，medium 表示来自二手解读页，low 表示仅摘要级。v1 中四条无法核实的声明显式排除并说明原因，而不是降级表述——这一纪律在 v2 中保持不变。

Every figure, paper and technical milestone carries a verifiable direct link and an individual confidence label: high for primary text or official pages, medium for secondary interpretation, low for abstract-level only. Four unverifiable claims from v1 were explicitly excluded with reasons rather than softened; this discipline is unchanged in v2.

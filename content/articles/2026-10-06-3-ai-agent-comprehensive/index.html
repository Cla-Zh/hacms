2.5 核心特性差异 (深度)

2.5.1 沙箱执行

  • Hermes: 7 个后端可选, 覆盖 $5 VPS 到 GPU 集群 + Serverless 唤醒
  • OpenClaw: 单 OS 原生方案 (macOS sandbox-exec / Linux bwrap / Windows restricted token + AppContainer)
  • DeepSeek Harness: 3 个后端 (bwrap Linux / Landlock Linux kernel LSM / Seatbelt macOS), policy-driven

2.5.2 记忆 / 持久化

  • Hermes: 多层 State 系统 — hermes_state_messages.py 107KB WAL, hermes_state_wal, hermes_state_sessions, hermes_state_compression, hermes_state_lockguard
  • OpenClaw: always-on 进程内存 + workspace DB (~/.openclaw/workspace.db)
  • DeepSeek Harness: 三层存储 — JSONL append-only + SQLite FTS5 retrieval + projection cache (Event Sourcing)

2.5.3 学习闭环 (Hermes 独有)

三工程中只有 Hermes 具有自学习能力:

  • Skill 自动生成 (从经验中创建可复用 skill 文档)
  • Skill 自我改进 (在使用中迭代更新)
  • FTS5 session search (跨会话语义检索)
  • Honcho user modeling (辩证式用户建模)

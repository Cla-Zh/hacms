玩家版图:头部 × 中国独角兽 × 美欧初创 × 学术开源

KV cache 不是单一公司的游戏,而是 25+ 家头部/独角兽/初创公司的多线作战。本章从四个维度展开:美国头部(OpenAI/Anthropic/Google/NVIDIA)、中国头部(DeepSeek/Moonshot/阿里/字节)、美欧初创(Anyscale/Fireworks/Modal/Together)、学术界(UC Berkeley/Stanford/MIT HAN/清华)。

2.1 美国头部公司:OpenAI / Anthropic / Google / NVIDIA / AWS

头部Anthropic · Prompt Caching 的定义者

核心产品:Claude API 的 cache_control 显式 breakpoint 机制,4 个 checkpoint 限制,5-min / 1-hour TTL 选项,Cache read 0.1× 折扣(90% off)。

关键时间线:2024-08-14 Public beta → 2024-12-17 API GA → 2025-04 AWS Bedrock GA → 2026-01 AWS Bedrock 1-hour TTL → 2026-02 Bedrock Claude 4.5 系列 4,096 最小 token。 [来源: Anthropic News, 2024-08-14]

经济账:10000 token prefix 复用 10 次的典型场景,net savings 78.5%(相比每次不缓存);复用率越高,节省越多(最多 90%)。

头部OpenAI · 自动 Prefix Caching 的开拓者

核心产品:自动 prompt caching,2024-10-01 上线,首发 GPT-4o / GPT-4o mini / o1-preview / o1-mini。Cache read 折扣从 2024 年的 50% off 提升到 2026 mid 的 90% off(与 Anthropic 看齐)。 [来源: OpenAI Blog, 2024-10-01]

机制:API 自动检测 ≥1024 token 共享前缀,以 128 token 增量匹配,无 write premium,无 opt-in,只是 prompt_token_details.cached_tokens 字段报告。

经济账:GPT-5.4 50,000 req/天,1,500 token 平均 prompt,90% cache hit 时,日账单从 $337.50 降到 $195.75(节省 42%)。

头部Google Vertex AI · Context Cache 1-hour TTL

核心产品:Vertex AI Context Caching,2024 上线,2025-05-08 加入零设置隐式缓存(Gemini 2.5 系列),所有 GCP 项目默认开启。Cache read 0.1×(90% off)。 [来源: Google Cloud Blog]

TTL:默认 1-hour,用户可自定义时长,按时长 × 缓存 token 数收费。

支持:Gemini 3.7 Flash, 最小缓存 2,048 token,最大可至 Gemini 2.5 Pro 1M token 上下文窗口。

头部NVIDIA · TensorRT-LLM KV cache reuse 5× TTFT

核心产品:TensorRT-LLM,2024-11-08 发布 KV cache early reuse 优化,实现 5× TTFT 加速。 [来源: NVIDIA Developer Blog, 2024-11-08]

三大机制:Early reuse(系统 prompt 边生成边共享)、Flexible block sizing(64→2 token,LLAM70B H100 7% TTFT 加速)、Priority-based eviction(智能追踪依赖,~20% hit 提升)。 [来源: NVIDIA KV cache reuse optimizations blog]

开源仓库:github.com/NVIDIA/TensorRT-LLM

头部AWS Bedrock · Prompt Caching 跨云

核心产品:Bedrock 上的 prompt caching,2025-04 GA,2026-01 加入 1-hour TTL 支持。 [来源: AWS Bedrock GA 公告, 2025-04] [来源: AWS Bedrock 1-hour TTL, 2026-01]

定价细节(2026-05 LiteLLM issue 验证):Vertex AI Claude Sonnet 4.6 的 cache write 5-min $3.75/M tokens,1-hour $6.00/M tokens;1-hour tier 是 5-min 的 1.6×。

2.2 中国独角兽:Moonshot / DeepSeek / 智谱 / MiniMax / 阿里 / 字节

独角兽Moonshot AI · Mooncake 的母体 + KV cache 教科书

总部:北京 · 成立:2023 · 创始人:杨植麟(清华 + Google Brain + CMU)

估值轨迹(Sacra + clay.com 验证):

  • 2024-02 Series B:$1B 融资 / 估值 $2.5B / 阿里领投
  • 2024-08 Series B Extension:$300M / 估值 $3.3B / 腾讯 + Gaorong Capital
  • 2025-01 Series C:$500M / 估值 $4.3B / IDG Capital 领投 $150M
  • 2025-02 新轮:~$700M 第一批 / 估值 $10B / 阿里腾讯 5Y Capital 跟投

股权结构:阿里持有 ~36% 股权(约 $0.7B 投资),腾讯也是大股东之一。 [来源: Sacra, Moonshot AI 估值档案]

核心产品:

  • Kimi:消费级 AI 助手,2024 年 7 月达成 unicorn status
  • Kimi K2:1T 参数 MoE,2025-07-20 部署在 128 H200,224k prefill / 288k decode tokens/s
  • Mooncake:FAST 2025 Best Paper,KVCache-centric disaggregated architecture
  • checkpoint-engine:Kimi K2 1T 参数,数千 GPU ~20s 同步

独角兽DeepSeek · MLA 的发明者

总部:杭州 · 母公司:High-Flyer 量化(2015 年成立的私募基金)· 创始人:梁文锋

核心模型:

  • DeepSeek-V2(arXiv:2405.04434, 2024-05-07 v1):236B 总参 / 21B 激活 / 128K 上下文,MLA KV cache 压缩 93.3%,相比 DeepSeek 67B 训练成本节省 42.5%
  • DeepSeek-V3(arXiv:2412.19437, 2024-12-27 v1):671B 总参 / 37B 激活 / 14.8T tokens 训练,仅 2.788M H800 GPU hours(约 $5.6M)

开源:DeepSeek-V2 / V3 全部开源权重 + MIT 协议。API 价格:DeepSeek-V3 API 价格为 GPT-4o 的 ~1/10。 [来源: arXiv:2412.19437, 2024-12-27]

独角兽智谱 AI · GLM 系列

总部:北京 · 成立:2019 · 创始人:唐杰(清华)

核心模型:GLM-4 / GLM-4.5 / GLM-5 系列,KV cache 设计使用 GQA(2024-2026 默认)。

估值:2024-2025 年累计融资数亿美元(具体未公开)。

独角兽阿里 PAI · Qwen 系列的 KV cache 路径

核心模型:Qwen-3 (2024-2025),Qwen-3-Next 长上下文 KV cache 优化,使用 GQA + 上下文压缩技术。

商业许可:Qwen3 系列采用 Apache 2.0 协议,允许商用。

DashScope:阿里云的 LLM 服务平台,提供 Qwen 模型的 API 与 KV cache 优化托管。

独角兽MiniMax · ABAB 模型

总部:上海 · 核心产品:Talkie(AI 角色扮演)+ Hailuo(视频生成)+ ABAB M3 大模型。

KV cache 策略:ABAB M3 使用 MoE + 长上下文,KV cache 优化集中于对话轮次复用与多模态融合。

2.3 美欧初创:Anyscale / Modal / Replicate / Fireworks / Together

独角兽Anyscale · Ray + vLLM 的工业派

总部:旧金山 · 成立:2019 · 创始人:Robert Nishihara 等 UC Berkeley

融资:2019-2021 Series A/B/C 共 $160M;Series C $100M @ $1B 估值(2021),由 Andreessen Horowitz + Addition 领投,参与 NEA / Intel Capital / Foundation Capital。 [来源: Anyscale Press, Series C 公告]

核心产品:Anyscale 平台(Ray 商业版),托管 Ray Serve + vLLM,聚焦 LLM serving 自动扩缩容、节点回收、Replicate Compaction 优化成本。 [来源: Anyscale LLM Serving Docs]

开源仓库:github.com/ray-project/ray(Ray GitHub 18,000+ stars)

客户:Amazon, Ant Group, LinkedIn, Shopify, Uber, Visa, Wildlife Studios(50% LLM 成本下降)。

独角兽Fireworks AI · 多模型 serving

总部:Redwood City, CA · 成立:2022 · 创始人:Lin Qiao(前 Meta PyTorch)

核心产品:Fireworks Inference Platform,KV cache aware 调度,微秒级 cold-start,多模型并发。

融资:Series C 2025,估值 ~$4B(根据公开报告,具体未官方披露)。

独角兽Modal Labs · Serverless GPU

总部:纽约 · 成立:2021 · 创始人:Erik Bernhardsson(前 Spotify)

融资:Series C 2025-04,估值 ~$1.5B,主打 serverless GPU + KV cache cold-start 优化。

独角兽Together AI · 长上下文 KV cache 复用

总部:旧金山 · 成立:2022 · 创始人:Vipul Ved Prakash

核心产品:Together Inference Platform,长上下文 KV cache 复用,支持 Llama 3 / Qwen / Mistral 等开源模型。

融资:Series B 2024-02 $106M / Andreessen Horowitz 领投。

独角兽Replicate · cog + cog-stream

总部:旧金山 · 创始人:Ben Firshman + Andreas Jansson

核心产品:Replicate 平台 + cog 开源工具,cog-stream 支持 KV cache 优化与流式推理。

早期FlexKV · Tencent × NVIDIA 分布式 KV store

仓库:github.com/taco-project/FlexKV(TACO Project)

核心特性:Tencent + NVIDIA + 社区共建,基于 Mooncake Store 的混合 KV cache 管理。
